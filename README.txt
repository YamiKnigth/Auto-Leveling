Auto Leveling — NeoForge 1.21.1 port/fork

This is an unofficial NeoForge 1.21.1 port/fork of Auto Leveling,
originally created by Daripher for Minecraft Forge.

Original repository:
  https://github.com/Daripher/Auto-Leveling

Original CurseForge page:
  https://www.curseforge.com/minecraft/mc-mods/auto-leveling

The further you move from the spawn, the stronger enemies become.
